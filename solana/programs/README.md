# Tradgents agent registry

Anchor 0.32.1, Solana SBF tools and Rust are required. From `solana/programs`:

```sh
anchor build
cargo build-sbf
cargo test --offline
cargo fmt --check
cargo clippy --offline --all-targets -- -D warnings
```

Anchor.toml explicitly lists `agent-registry` as a workspace member. Without that entry, `anchor build` can return success without building this crate. The Anchor test script runs the Rust host tests; `cargo test --offline` is the direct command and needs no wallet/validator. Build outputs are `target/deploy/agent_registry.so` and `target/idl/agent_registry.json`. Existing program-keypair material stays ignored under `target/`; no wallet files are committed or generated by our test suite.

## Review and coverage

The existing security checks were confirmed: configuration initialization requires the deployed program's ProgramData and its upgrade authority as signer, preventing first-caller configuration capture. Initialize before revoking upgrade authority; immutable deployments cannot initialize through this instruction. Only admin can update configuration. Admin **or guardian** can pause, unpause and slash; unpause cannot restore a slashed agent. This is the intended shared moderation authority, not an admin-only unpause policy.

The agent wallet and payer must both sign registration. Agent and vault are initialized once at wallet-derived PDAs; Anchor's `init` constraints prevent double registration. Beneficiary is immutable. Withdrawals require the agent signature and elapsed registration cooldown, and fail for paused, slashed or already withdrawn agents. Slash sends only the recorded bond to the configured system-owned treasury. Withdraw and slash preserve the rent-exempt vault balance; checked arithmetic guards balances and timestamps. The vault/agent remain allocated after withdrawal; rent and any unsolicited excess lamports are not reclaimed by these instructions.

Changes: corrected Anchor workspace discovery and the missing test script target; synchronized the placeholder declared/localnet/devnet IDs to the pre-existing program keypair; extracted bond state and rent-preserving arithmetic for deterministic host testing. No instruction arguments/account layouts were changed. Rust's `solana` target cfg is explicitly declared for warning-free host analysis.

The Rust suite covers minimum bond, cooldown before/at/after expiry, successful held-bond withdrawal, repeated withdrawal, paused/slashed withdrawal denial, rent preservation/underfunding, arithmetic overflow, signer metadata, missing agent co-signature and actual generated Anchor entrypoint moderation/authorization. Host tests integrate serialized account data with Anchor dispatch. They do **not** simulate Solana runtime CPI, account creation or transaction rollback. Double registration is reviewed through Anchor `init` but is not executed in a validator. No local validator, LiteSVM or solana-program-test is installed; no new dependencies were added.

## Human-run local deployment rehearsal

Requires a separately available `solana-test-validator` and an existing funded local-test wallet. No key generation or airdrop is included.

```sh
solana-test-validator --ledger ./test-ledger
```

In another terminal:

```sh
cd solana/programs
export ANCHOR_WALLET=/absolute/path/to/existing-funded-local-wallet.json
anchor build
anchor deploy --program-name agent_registry --program-keypair target/deploy/agent_registry-keypair.json --provider.cluster localnet --provider.wallet "$ANCHOR_WALLET"
```

Local deployment/transaction rehearsal cannot be claimed here because the validator binary is unavailable. Host tests and SBF builds are the reproducible local evidence.

## Exact devnet deployment commands (human only)

Use an already funded wallet; keep the existing matching program-keypair file at the path below. The wallet must retain upgrade authority until configuration has been initialized.

```sh
cd solana/programs
export ANCHOR_WALLET=/absolute/path/to/existing-funded-devnet-wallet.json
export PROGRAM_ID=73Gga8nZPh8ohGCzVZ7PKnxKJR1Zp8FVDskdPjabr3WA
test "$(solana address --keypair target/deploy/agent_registry-keypair.json)" = "$PROGRAM_ID"
anchor build
anchor deploy --program-name agent_registry --program-keypair target/deploy/agent_registry-keypair.json --provider.cluster devnet --provider.wallet "$ANCHOR_WALLET"
```

Configure `initialize_config(guardian, treasury, minimum_bond, cooldown)` with the upgrade-authority wallet using the generated IDL, registry ProgramData account and the `config` PDA. Guardian/treasury must be nonzero, minimum bond positive and cooldown nonnegative. Deployment alone does not initialize configuration. No devnet deployment or initialization was performed here.
