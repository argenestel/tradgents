# Monad agent kit

`tradgents` is a keyless CLI; `tradgents-signer` is the only process that reads the owner's private-key file. `MONAD_NETWORK=mainnet` is the default (chain ID 143); explicit `MONAD_NETWORK=testnet` selects chain ID 10143. The signer accepts bounded JSON intents over a Unix socket and supports only profile WMON/USDC exact-input swaps through the profile-pinned Uniswap V2 Router02. It constructs and validates calldata itself, checks the recipient/path/amount/deadline, simulates with `eth_call`, enforces USD limits, reserves spend durably before sending, and only exact-approves the router. It supports domain-separated Tradgents `Register`, `Post`, and `Call` EIP-712 messages; there is no arbitrary-sign or raw-transaction API.

## Operator setup

1. Create a root-owned JSON policy file for the selected network: `network: "mainnet"` with chain ID `143` (default), or `network: "testnet"` with chain ID `10143`. Include the deployed registry address, agent wallet and explicitly allowed registration owner wallet, profile WMON (18 decimals) and USDC (6 decimals), pinned router/factory, per-trade/day caps, gas/slippage limits, per-feed price ages, and a pool-liquidity floor. Keep its mode at `0640` or stricter (never world-readable or group-writable). Pyth freshness defaults to 3600 seconds per feed, matching its approximately hourly heartbeat; set `maxPriceAgeSeconds.WMON` and `.USDC` separately when needed. The registry address must match a deployment verified by the operator; no address is shipped here.
2. Run the signer as a dedicated OS user. Provision `SIGNER_KEY_FILE` out of band, owned by that user and mode `0600`; never put key material in environment examples, shell commands, or this repo. `SIGNER_DIR` must be signer-owned mode `0700` and stores the spend ledger and `PAUSE` file.
3. For a separate CLI/agent user, place `TRADGENTS_SIGNER_SOCKET` in a root-controlled runtime directory. Configure ACL/group traversal so the signer can create the socket and only the intended agent group can connect; do not make the directory agent-writable. Set `TRADGENTS_SIGNER_SOCKET_MODE=0660` and explicitly set `TRADGENTS_SIGNER_SOCKET_GID` to that numeric group ID. The daemon binds under a restrictive umask and only then changes ownership/mode. The default socket mode is `0600` and is suitable when the client runs as the signer UID. Do not grant the agent user access to the signer directory, policy, or key.
4. Inject `MONAD_NETWORK=mainnet|testnet` (default `mainnet`), optional matching `MONAD_CHAIN_ID`, optional `MONAD_RPC_URL`, `REGISTRY_ADDRESS`, `SIGNER_DIR`, `SIGNER_POLICY_FILE`, `SIGNER_KEY_FILE`, and socket settings through the process manager. For testnet, also inject `TESTNET_V2_ROUTER`, `TESTNET_V2_FACTORY`, and `TESTNET_USDC` from `monad/deploy/out/testnet.json`; canonical testnet WMON is the default (`TESTNET_WMON` is only for a local fixture). The signer verifies the profile chain ID and bytecode for registry, router, factory, WMON, USDC and Pyth, then verifies token metadata and USDC's six decimals.
5. Install with `pnpm install`, then run `pnpm typecheck` and `pnpm test` (the local end-to-end swap test requires `forge` and Anvil). Start `pnpm signer` under the signer account and expose the same socket path to the keyless CLI. Use `pnpm tradgents -- status` or `pnpm tradgents -- swap --in WMON --out USDC --amount 0.2 --max-slippage-bps 50`.

The signer validates the oracle-priced quote against a pool-liquidity floor, diffs simulated wallet token balances and exact router allowance, then reserves notional plus bounded approval/swap gas before broadcast. `TESTNET_FIXED_PRICES=true` is an explicit testnet-only fallback for stale/unavailable Pyth feeds and requires `TESTNET_MON_PRICE_USD`; MON uses that value and test USDC is $1.00. Fallback quotes are labeled `estimated`/`testnet-fixed-prices`, never accepted on mainnet, and must not be represented as oracle prices. A pre-broadcast simulation failure reserves nothing; once any transaction is sent, the reservation remains. The durable spend ledger includes the pool liquidity and gas reserve used. A `PAUSE` file in `SIGNER_DIR` blocks all trade and signing requests. This is an OS-isolation boundary, not an on-chain session-key policy. Use only funds the owner can afford to lose.
