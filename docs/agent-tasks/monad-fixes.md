# Task: fix the Monad review findings

Scope: `monad/api`, `monad/agent-kit`, `monad/contracts` only. No git commands, no transactions, no keys, no paid APIs. Read `docs/PRODUCTION.md` (sections 4 and 5) first. For every item below: confirm it by reading the code (say so in your report if the finding is wrong, with the reason), fix it, and add a test that fails before the fix. Run `tsc --noEmit` and the vitest suites (and `forge test` for the contract) at the end; all must pass.

## Must fix (real-money blockers)

1. **Swap output is not checked against the oracle** (`agent-kit/src/trade.ts`). `minOut` comes from `getAmountsOut` alone, so a manipulated V2 pool passes. Require the quoted output to be at least the oracle value of the input times (1 - deviation tolerance), reject pairs whose reserves are below a USD liquidity floor (read reserves from the pair, price them with the oracle), and cap `maxSlippageBps` at a tighter ceiling in the policy schema.
2. **Two signers can run at once** (`agent-kit/src/signer.ts`, `spend-ledger.ts`). Startup unlinks a live socket, and `reserve()` is read-check-write without a cross-process lock. Refuse to start if the socket still accepts connections; take an exclusive lockfile (`SIGNER_DIR/signer.lock`, with pid and liveness check) for the whole life of the process; make the ledger's read+check+append atomic across processes (lock file around it); create the socket with a restrictive umask so it is never briefly more open than configured.
3. **WMON wrap and unwrap read as unsupported** (`api/src/indexer.ts`, `ledger.ts`). The indexer only decodes `Deposit`/`Withdrawal` from the Transfer-filtered logs, never from the receipt, so `tx.wrap` is never set. Decode them from `receipt.logs`; also treat a transaction to WMON whose only deltas are MON and WMON as a wrap even without the event. Wraps must be neutral (move cost lots between MON and WMON, no realization, no unsupported flag).
4. **Opening inventory has no cost basis** (`api/src/indexer.ts:211`, `ledger.ts:75`). The indexer passes `openingLots: []`, which is truthy, so the seeding branch is skipped. Seed lots from the opening balances at the opening prices. Treat an empty array as missing. Never create lots from an unmatched sell (`ledger.ts` swap path pushes `costUsd: 0`): an unmatched sell must use the sale price as its basis (no gain) and flag the agent as having unknown basis (ineligible).
5. **The integrity check overwrites cached balances with chain balances** while keeping replay lots (`indexer.ts:244`). On a mismatch: do not write mixed state. Mark the agent drifted (persisted in the database, so a restart does not hide it), log the per-token differences, rebuild lots, balances and equity from raw transactions plus stored price samples, and keep the agent ineligible until a rebuild agrees with the chain exactly.
6. **Lock loss does not stop the worker** (`api/src/pg.ts`, `indexer.ts`). A dropped lock session only aborts the loop; `indexBlock` can keep writing while a second worker takes over. Pass the abort signal into `indexBlock` and RPC calls, stop writing the moment it fires, and make the process exit non-zero. Make `ledger_entries` idempotent per `(agent, tx_hash, token, kind)` (unique index plus upsert) so a replay can never duplicate.
7. **The registry is only scanned inside `indexBlock`, gated on having agents** (`indexer.ts:56`). With no agents the cursor never advances and registry events before the first agent are lost. Walk the finalized registry logs from the stored cursor on every cycle regardless of agents, store the events, and let projection (verification, bond) use them.
8. **Signed writes from the shipped CLI always fail**: the CLI sends 128-bit random nonces but `consumeNonce` requires 0, 1, 2 ... Either change the API to accept any unused nonce (preferred: a `used_nonces` table keyed by wallet and nonce with expiry, which also removes the ordering problem for concurrent writes) or have the CLI fetch the next nonce. Add an end-to-end test that signs with the kit's `signTradgentsMessage` and posts to the API app.

## Should fix

9. Oracle freshness vs heartbeat (`trade.ts`, `policy.ts`, API price code): Pyth Monad push feeds update on a heartbeat of about an hour. Make the freshness limit configurable per feed with a documented default that matches the heartbeat, persist the pair/pool liquidity used for the price, and mark prices from sources below the liquidity floor `estimated` and ineligible.
10. FIFO USD cost uses `Number(wei)` divisions that lose precision above 2^53 (`ledger.ts:64`). Allocate cost with integer (bigint) math, and convert to a float only when producing USD for display.
11. Gas is outside the spend budget (`trade.ts:54`): Monad charges `gas_limit x gas_price`. Add the USD cost of approval plus swap gas (limit x price x oracle) to the reservation. A failed simulation before broadcast must release the reservation (nothing was sent).
12. The simulation only checks that `eth_call` does not revert. Also diff the wallet's token balances and the router allowance after the simulated call and reject any extra mover.
13. Permissions: policy file mode 0640 is the loosest allowed and must not be world-readable; socket mode 0660 only when explicitly configured with a group.
14. The opening equity point stores `startCapitalUsd` as its flow (`store.ts:35`): store the true opening flow consistently so no consumer is misled.
15. Index the `safe` block as unconfirmed rows (status `safe`) and promote them on finalization, so `/v1/meta` can report unconfirmed activity, not just a lag number. If this is too large, document the gap in the README instead and say so in your report.
16. `AgentRegistry.sol`: `setUnbondDelay(0)` closes the slash window immediately, so enforce a minimum delay; override `renounceOwnership` to revert; add tests.
17. Verify on chain 143 that the USDC token's decimals are 6 (read it from the contract at signer and worker startup and fail if it differs from the policy, rather than trusting a constant).
